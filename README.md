### 🧑‍💻 About me

I'm a **DevOps / Systems Engineer** with 6+ years of experience designing, automating and running cloud infrastructure on **AWS, Azure and GCP**.
I enjoy building platforms from scratch, turning legacy setups into clean, version-controlled IaC, and making deployments boring (in a good way).

- ☸️ Running and upgrading production **Kubernetes** clusters across AWS and Azure
- 🏗️ Designing cloud architecture, IaC and delivery pipelines **from zero** for startups
- ☁️ Migrating on-prem applications to **cloud-native**, highly available setups
- 🔁 Implementing **GitOps** with Argo CD and reusable CI/CD workflows
- 🌬️ Zero-downtime upgrades of **Apache Airflow** clusters
- 📈 Building observability with Prometheus, Grafana, Datadog and New Relic
- 🔐 Hardening cloud security posture — IAM and access-control remediation
- 🎓 BSc in Information Technology & Computer Science — NPUA, Yerevan
- 🌍 Armenian (native) · English (fluent) · Russian (fluent)
